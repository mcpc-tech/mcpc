# Installation

This guide will walk you through the process of installing and setting up the
**@mcpc/core** package, a library for building scalable agentic MCPs.

# Prerequisites

Before you begin, ensure you have the Nodejs(or Deno/Bun) runtime environment
installed.

# Installation

To add the `@mcpc/core` package to your project, open your terminal and run the
following command:

## Install from npm registry

```bash
# npm
npm install @mcpc-tech/core

# pnpm
pnpm add @mcpc-tech/core

# yarn
yarn add @mcpc-tech/core

# bun
bun add @mcpc-tech/core
```

## Install from JSR

```bash
# npm
npx jsr add @mcpc/core

# pnpm
pnpm add jsr:@mcpc/core

# yarn
yarn add jsr:@mcpc/core

# deno
deno add jsr:@mcpc/core

# bun
bunx jsr add @mcpc/core
```

This command will download the package and add it as a dependency to your
project's configuration file.

Now see [Usage Guide](./create-your-first-agentic-mcp.md) to get started using
`@mcpc/core`
